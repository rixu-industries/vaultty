# Security Policy

Vaultty stores credentials, so it takes security flaws seriously.

## How to report a vulnerability

Do not open a public issue. Use GitHub private security advisories: the **Security → Report a vulnerability** tab in
[rixu-industries/vaultty](https://github.com/rixu-industries/vaultty/security/advisories/new).

Include the affected version, the operating system and the steps to reproduce it. We will try to respond within a few
days and publish the fix before disclosing the details.

## Supported versions

Only the latest published version.
